# Changelog

All notable changes to FocusFlow are documented in this file.

## [2.3.1] - 2026-11-21

### Fixed
- **Recurring Schedules & Daemon Hardening (`pkg/schedule/schedule.go`, `cmd/focusflow/main.go`):** Added `IsActiveAt`, normalized unnormalized `rule.Days` inside `WindowForDate`, guarded DST spring-forward zero/negative windows, aligned UTF-8 rune length validation with Python, and completed deterministic overlap tie-breaking (`Start` -> `End` -> `Name` -> `ID`). In `focusflow schedule run`, added fast `--strict` validation, explicit warnings when falling back from deleted profiles to `study`, hosts-before-`StartSession` ordering and external-stop hosts rollback, accurate remaining-duration planning on mid-window entry, wake-from-sleep detection past `win.End` (immediate shield rollback without crediting sleep hours), and bounded pruning of `handledWindows`.
- **Lifecycle Hooks Process-Tree Cleanup, Privilege & Race Hardening (`pkg/engine/hooks*.go`):** Hardened `ResolvePosixHookPrivilege` to reject `SUDO_GID=0` and `math.MaxUint32` (`(uid_t)-1`) sentinel values; added `Setpgid: true` + `-pgid` `SIGKILL` cancellation on POSIX and `taskkill.exe /T /F` child-tree cancellation + newline normalization on Windows; rejected NUL bytes in hook commands; and mutex-protected `limitedBuffer` to eliminate race conditions after `WaitDelay`.
- **Desktop Notifications Escaping & Bounded Concurrency (`pkg/engine/notify*.go`):** Added bounded in-flight concurrency (`DefaultMaxConcurrentNotifications = 4`) to `Notifier.SendAsync` so bursts never leak goroutines; hardened `SanitizeNotificationText` against C1 control characters, `\u2028`/`\u2029` separators, and `\uFFFE`/`\uFFFF`; escaped PowerShell Unicode smart single quotes (`\u2018`..`\u201B`) in `EscapePowerShellSingleQuoted`; escaped Pango XML markup in Linux `notify-send` body; deduplicated Windows `FOCUSFLOW_NOTIFY_*` env vars, fixed empty-body WinForms BalloonTip crash, and set `WaitDelay` across all OS notification runners.
- **Malformed `config.json` Graceful Degradation, Timezone Day-Bucketing & Heatmap Edge Cases (`pkg/profile/profiles.go`, `pkg/storage/store.go`, `pkg/tui/heatmap.go`, `focusflow_core/config.py`, `focusflow_core/storage.py`, `FocusFlowGUI.py`):** Replaced rigid full-struct `config.json` unmarshaling in Go with per-field lenient decoding so wrong-typed fields (`schedules: null`, `schedules: "bad"`, `hooks: null`, `notifications_enabled: "invalid"`) degrade cleanly without wiping valid settings; enforced strict string typing in Python `ScheduleRule.from_dict`; aligned Go and Python local day-bucketing for naive timestamps, lowercase `'z'` RFC3339, and naive `now` arguments; made Go heatmap week counts DST-safe via UTC calendar midnights with exact in-window totals; and hardened `FocusFlowGUI.py` heatmap resize bounds, empty-state rendering, midnight date alignment, canvas `<Leave>` hover reset, and System tab sync.

## [2.3.0] - 2026-11-21

### Added
- **Automated Recurring Focus Schedules (`pkg/schedule`, `focusflow schedule`):** Added recurring weekday/overnight schedule rules (`schedules` in `config.json`) with `focusflow schedule list|add|remove|next|run [--json]`. Supports day ranges with weekday wrap-around (`mon-fri`, `fri-mon`, `daily`, `weekends`), overnight windows crossing midnight (`22:00`–`02:00`), exact next-window prediction (`schedule next`), and a lightweight daemon runner (`schedule run --check-interval 30s`) that engages and releases focus shields automatically with graceful `SIGINT`/`SIGTERM` rollback.
- **90-Day Contribution Heatmap (`pkg/tui/heatmap.go`, `focusflow stats --heatmap`, `FocusFlowGUI.py`):** Added a GitHub-style 13-week × 7-day focus intensity heatmap calibrated against `daily_goal_minutes`, displaying month headers, intensity legend, active streak, and longest streak (`longest_streak_days` in Go & Python `AnalyticsSummary`). Automatically degrades to pure ASCII (`[ ] [.] [o] [O] [#]`) under `--no-color` or `NO_COLOR`. Added a native zero-dependency Catppuccin Mocha 90-day heatmap canvas with hover tooltips in the Python desktop HUD.
- **Zero-Dependency Native OS Desktop Notifications (`pkg/engine/notify*.go`):** Added non-blocking native desktop notifications on sprint start, break start, and session completion (Windows WinRT Toast with WinForms BalloonTip fallback reading env-isolated strings; macOS `osascript` argv-isolated `display notification`; Linux `notify-send` with silent headless fallback). Controlled via `--no-notify`, `notifications_enabled` in `config.json`, or `FOCUSFLOW_NO_NOTIFY=1`.
- **Privilege-Hardened Lifecycle Hooks (`pkg/engine/hooks*.go`, `--on-start` / `--on-break` / `--on-end`):** Added persistent `hooks` in `config.json` and per-session CLI hook flags exporting `FOCUSFLOW_EVENT`, `FOCUSFLOW_PROFILE`, `FOCUSFLOW_SESSION_ID`, and `FOCUSFLOW_MINUTES` with strict `10s` timeouts and non-fatal warning reporting so failing hooks never abort hosts rollback. On POSIX, elevated `sudo` invocations drop privileges via `SysProcAttr.Credential` (`SUDO_UID`/`SUDO_GID`) before executing hooks, and pure root executions refuse arbitrary hooks unless `--allow-root-hooks` is explicitly passed.
- **Go <-> Python v2.3.0 `config.json` Round-Trip Sync (`focusflow_core/config.py`, `FocusFlowGUI.py`, `tests/test_v230_features.py`):** Added full schema validation and lossless preservation of `schedules`, `hooks`, and `notifications_enabled` across Go CLI and Python HUD saves, plus a desktop notifications toggle and automation sync status indicator in Tab 5 (`[05] SYSTEM`).

## [2.2.2] - 2026-11-15

### Fixed
- **Dual-Stack Hosts Anti-Tamper Bypass & Custom-Hosts Preservation (`pkg/engine/hosts.go`, `focusflow_core/hosts.py`):** Hardened `VerifyOrReapply` / `verify_or_reapply` to require `MarkerBegin` strictly preceding `MarkerEnd` and to parse only active uncommented IPv4 (`0.0.0.0`) and IPv6 (`::`) mappings inside the managed block across both root domains and `www.` subdomains—catching commented-out rules (`# 0.0.0.0 youtube.com`), removed `www.` entries, and out-of-block spoofing immediately. Narrowed `isLikelyFocusFlowSinkholeLine` / `_is_likely_focusflow_sinkhole_line` during truncated-block recovery so user `127.0.0.1` aliases and non-FocusFlow `# ... managed` comments are never deleted.
- **Cross-Process Atomic File I/O, Corrupt-Reset Retry, `save_gui_prefs` & Self-Export Safety (`pkg/storage/store.go`, `pkg/profile/profiles.go`, `pkg/engine/hosts.go`, `focusflow_core/storage.py`, `focusflow_core/config.py`, `FocusFlowGUI.py`, `cmd/focusflow/main.go`):** Removed non-atomic `O_TRUNC` write fallbacks in Go in favor of 5-attempt atomic rename retries (`25ms` backoff), added 3-attempt read/unmarshal retries (`25ms` backoff) before resetting `sessions.json`/`config.json` as corrupt across Go and Python, made `FocusFlowGUI.py` `save_gui_prefs` atomic (`tempfile.mkstemp` + `fsync` + `os.replace` retry), and serialized `focusflow export --out <path>` / `SessionStore.export_to_file` prior to atomic staging so exporting to `sessions.json` never self-truncates session history.
- **Multi-Cycle Hardcore Break Lease Refresh & Read-Only Command Isolation (`cmd/focusflow/main.go`, `pkg/engine/hosts.go`, `focusflow_core/hosts.py`, `FocusFlowGUI.py`):** Refreshed `ExpectedEndAt` and persisted the updated `hosts` write-ahead journal when entering continuous `hardcore` breaks, skipped mutating `runStartupAutoRecovery()` on purely read-only CLI commands (`status`, `stats`, `list`, `export`), and introduced a 15-minute grace window (`AlivePIDLeaseGrace` / `ALIVE_PID_LEASE_GRACE`) for live owner PIDs before treating expired leases as orphaned while preserving immediate recovery for dead PIDs.
- **POSIX `sudo` State-Dir Split-Brain, Protected Process Denylist, `/proc/<pid>/exe` Resolution, Installers & CI/Release (`pkg/storage/store.go`, `pkg/engine/fileio_posix.go`, `pkg/engine/sanitize.go`, `pkg/engine/process.go`, `focusflow_core/paths.py`, `focusflow_core/privileges.py`, `focusflow_core/sanitize.py`, `focusflow_core/supervisor.py`, `install.ps1`, `install.sh`, `.github/workflows/ci.yml`, `.github/workflows/release.yml`):** Forwarded `FOCUSFLOW_HOME` across `ElevateSelf` / `elevate_self`, added `SUDO_USER` home fallback when running as `root` without `FOCUSFLOW_HOME`, fixed top-level `from ctypes import wintypes` on Windows in `privileges.py`, expanded the protected process denylist with 14 critical POSIX shells/daemons/compositors (`sh`, `bash`, `zsh`, `dash`, `fish`, `sshd`, `sudo`, `login`, `dbus-daemon`, `gnome-shell`, `plasmashell`, `xorg`, `xwayland`, `windowserver`), resolved `/proc/<pid>/exe` unconditionally regardless of `comm` length, hardened `install.ps1` (`PSModulePath` Desktop 5.1 sanitization, pure `.NET` helpers, `ReadOnly` clearing, zero host-killing `exit`) and `install.sh` (atomic `.tmp.$$` + `mv -f`), and enabled `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: "true"` plus guarded `zip` installation in GitHub Actions workflows.

## [2.2.1] - 2026-11-14

### Fixed
- **`focusflow stop` Stale `"running"` Sessions & Concurrent Re-Apply Race (`cmd/focusflow`, `pkg/storage`, `focusflow_core/storage.py`, `FocusFlowGUI.py`):** Fixed `focusflow stop` so it always finalizes any active `"running"` records in `sessions.json` as `"aborted"` with computed elapsed minutes—even when running in unprivileged `PROCESS-ONLY` mode or during a break with no active `hosts` journal. Active `focusflow start` CLI loops and the desktop HUD now detect external session termination via `IsSessionRunning` / `is_session_running` and exit cleanly without mistaking the rollback for `hosts` tampering or overwriting aborted sessions as `completed: true`.
- **UTF-8 BOM, Empty File & Corrupted JSON Resilience (`pkg/storage`, `pkg/profile`, `pkg/engine`, `focusflow_core/config.py`, `focusflow_core/storage.py`, `focusflow_core/hosts.py`):** Stripped UTF-8 BOM (`\xef\xbb\xbf`, emitted by Windows PowerShell `Set-Content -Encoding UTF8`) across `config.json`, `sessions.json`, `hosts.focusflow.journal.json`, and `gui_settings.json`, preventing `json.Unmarshal`/`json.load` failures and silent history wipes. Added 0-byte tolerance, `.corrupt.bak` preservation prior to self-healing malformed `config.json`/`sessions.json` files, and null-safe field coercion in Python `SessionRecord.from_dict` and `FocusProfile.from_dict`.
- **Domain Sanitization Bypasses & Unicode Port Validation (`pkg/engine/sanitize.go`, `focusflow_core/sanitize.py`):** Blocked `www.<reserved>` (`www.ip6-localhost`, `www.ip6-loopback`, `www.broadcasthost`, `www.127.0.0.1`), `home.arpa` / `*.home.arpa` / `*.invalid`, scheme-relative `//` URLs, consecutive trailing dots (`..`), and non-standard hex/octal IPv4 literals (`0x7f.0.0.0x1`) identically in Go and Python. Fixed Python `sanitize_domain` raising uncaught `ValueError` instead of `DomainValidationError` on non-ASCII Unicode superscript port digits (e.g. `reddit.com:\u00b2`).
- **Read-Only `hosts` Attribute Handling (`pkg/engine/fileio_windows.go`, `pkg/engine/fileio_posix.go`, `focusflow_core/hosts.py`):** Temporarily clear and restore `FILE_ATTRIBUTE_READONLY` around `ReplaceFileW` and fallback writes on Windows, and apply `0444` POSIX modes only after writing/fsyncing temporary `hosts` staging files so read-only `hosts` files can be engaged and rolled back cleanly.
- **CLI Subcommand Flag Ordering & Positional Argument Validation (`cmd/focusflow/main.go`):** Implemented FlagSet-aware interspersed flag parsing (`parseInterspersedFlags`) across all subcommands so flags placed before or after positional arguments (e.g. `focusflow start dev --minutes 30`, `focusflow profile create myprof --minutes 45`, `focusflow profile show dev --json`, `focusflow add site reddit.com --json`, `focusflow stop --json`) work consistently, unknown flags never swallow positional `<name>` tokens, and unexpected positional arguments (such as `focusflow goal 90`) fail fast instead of being silently ignored.
- **Desktop HUD Early Break Leak, Double-Counted Block Telemetry, Hardcore Break Lockdown & Friction Regeneration (`FocusFlowGUI.py`):**
  - Finalized active work sprints as `"aborted"` when taking an early manual break (`[TAKE BREAK]`), eliminating orphaned `"running"` records in `sessions.json`.
  - Fixed `DISTRACTIONS KILLED` KPI double-counting `session_blocked_count` after session completion or abort.
  - Kept `hosts` sinkhole, `ProcessSupervisor`, and `AntiCheatGuard` continuously active during Pomodoro breaks in `hardcore` mode (matching Go CLI behavior).
  - Regenerated fresh 16-character tokens and redrew the `FrictionChallengeDialog` canvas on mismatch, synchronized live custom blocklist edits during active sessions, and added automatic fallback to `study` when a selected custom profile is deleted externally.
- **Python JSON Export Local Timezone Alignment (`focusflow_core/storage.py`):** Fixed `SessionStore.export_json_string()` defaulting `now` to UTC instead of the local system timezone, aligning exported `today_focus_minutes`, `active_streak_days`, and `daily` buckets with `compute_analytics()` and Go `ExportJSON`.
- **Installer Checksum BOM & Uppercase Version Tag Handling (`install.ps1`, `install.sh`):** Stripped UTF-8 BOM and CRLF line endings when parsing `checksums.txt` in `install.ps1` and `install.sh`, and normalized uppercase `V` prefixes (`FOCUSFLOW_VERSION=V2.2.1`) in `install.sh`.

## [2.2.0] - 2026-11-14

### Added
- Custom Named Profiles (`focusflow profile list|show|create|delete [--json]`) with strict slug validation (`^[a-z0-9][a-z0-9_-]{0,31}$`), `--from` profile cloning, RFC-1123 domain sanitization, protected process denylist enforcement, and built-in profile deletion/overwrite guards across both Go (`pkg/profile`) and Python (`focusflow_core/config.py`).
- Dynamic custom profile loading and selection in `FocusFlowGUI.py` (Catppuccin Mocha zero-emoji HUD) synchronized seamlessly with `ConfigStore.profiles`.
- Daily Focus Goals (`daily_goal_minutes`, defaulting to `120` and clamped to `5..1440`) across Go and Python `config.json` stores, plus `focusflow goal [--minutes <N>] [--json]` CLI command and daily progress telemetry (`Today: X / Y min [Z%]`, `today_focus_minutes`, `daily_goal_minutes`, `daily_goal_progress_pct`) in `focusflow stats`, `focusflow status`, Python `SessionStore`, and the desktop HUD.
- Multi-Cycle Pomodoro Sprint Engine (`focusflow start --cycles <N> --break <min>`) supporting 1..24 sequential work/break cycles, `[CYCLE k/N]` TUI progress indicators, immediate per-sprint `sessions.json` persistence, automatic `hosts` shield pause during recovery breaks (kept continuous under `--strict hardcore`), and clean `SIGINT`/`SIGTERM` rollback at any work or break phase.
- Universal one-line installers `install.sh` (Linux and macOS `amd64`/`arm64`) and `install.ps1` (Windows `amd64`/`arm64`) with mandatory SHA-256 verification against `checksums.txt` before extraction.
- Expanded Go (`pkg/profile`, `pkg/storage`, `pkg/tui`, `cmd/focusflow`) and Python (`pytest`) test suites covering Go <-> Python custom profile & daily goal interoperability, multi-cycle Pomodoro execution, signal rollback, and SHA-256 installer verification.

## [2.1.0] - 2026-11-10

### Added
- Unified standard-library Python core package (`focusflow_core/`) shared with `FocusFlowGUI.py` and 100% interoperable with the Go CLI (`config.json`, `sessions.json`, `hosts.focusflow.journal.json`).
- Crash-safe write-ahead rollback journal (`hosts.focusflow.journal.json`) and automatic startup orphan recovery (`RecoverIfOrphaned`) across both Go CLI and Python HUD.
- Dual-stack IPv4 (`0.0.0.0`) + IPv6 (`::`) `hosts` sinkholing with expanded Anti-DoH endpoints (`dns.adguard-dns.com`, `dns.nextdns.io`, `doh.cleanbrowsing.org`, `doh.dns.sb`, `freedns.controld.com`) and mid-session tamper verification.
- Zero-dependency Python Win32 process supervisor using `ctypes` `CreateToolhelp32Snapshot` (`Process32FirstW`/`Process32NextW`) and `TerminateProcess`.
- Critical protected process and PID denylist across Go and Python (`csrss.exe`, `lsass.exe`, `svchost.exe`, `explorer.exe`, `python.exe`, `focusflow.exe`, `wt.exe`, etc.), plus `SystemInformer.exe` in hardcore `AntiCheatGuard`.
- New CLI commands and flags: `focusflow doctor`, `focusflow recover`, `focusflow export [--format json|csv] [--out <file>]`, `--elevate`, `stats --days`, and `--json` output on `status`, `list`, `stats`, `doctor`, and `recover`.
- Non-pasteable 16-character alphanumeric Friction Challenge in strict mode, `PER_MONITOR_AWARE_V2` High-DPI scaling, `[ELEVATE ADMIN]` UAC action, and JSON/CSV/PNG telemetry exports in the desktop HUD.
- Hermetic Go and Python (`pytest`) test suites and multi-OS CI matrix (`Go 1.23.x`/`1.24.x` and `Python 3.11`–`3.14`), plus `windows/arm64` release artifacts.

### Changed
- Replaced drifted sleep countdowns with `time.monotonic()` phase deadlines and paused modal transitions so break timers never burn in the background while dialogs are open.
- Preserved Windows `hosts` DACLs via `ReplaceFileW` and POSIX permissions with `fsync` and 5x/40ms sharing-violation retries.
- Fixed Linux `/proc` process scanning so `ps` is never spawned on zero-match ticks and 15-byte `TASK_COMM_LEN` truncated names resolve via `/proc/<pid>/exe` and `/proc/<pid>/cmdline`.
- Purged seeded placeholder stats in favor of live telemetry computed from `sessions.json`.
- Standardized CLI and HUD on a strict zero-emoji Catppuccin Mocha systems aesthetic.

### Removed
- Retired duplicate unmaintained Rust prototype (`Cargo.toml`, `src/`) and legacy V1 script (`legacy/FocusFlowV1.py`).
