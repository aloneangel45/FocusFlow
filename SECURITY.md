# Güvenlik Politikası

## Desteklenen Sürümler

| Sürüm | Destekleniyor mu?  |
| ----- | ------------------ |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x:                |

## Güvenlik Açığı Bildirimi

FocusFlow sistem düzeyinde proses ve DNS/hosts filtrelemesi yaptığı için güvenlik bizim için kritik öneme sahiptir.
Bir güvenlik açığı tespit ettiğinizde lütfen genel Issue açmak yerine `security@aloneangel.dev` adresine bildiriniz veya GitHub Security Advisory oluşturunuz.
Bildirilen açıklar en geç 48 saat içinde değerlendirmeye alınacaktır.
